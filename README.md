# 成績ノート (seiseki)

개념반·단풀반·실전반 성적을 한 곳에 모으는 시스템입니다.

- **학생**: 퇴실퀴즈와 같은 번호(예: KM482919)로 들어와 내 성적을 보고, 숙제한 문제집 쪽 사진을 올립니다.
- **강사**: 종이 시험지 답안을 숫자로 입력하면 바로 채점되고, 숙제 제출 확인, 월초 명단 반영·번호 발급, 월말 표 복사·엑셀 내려받기를 합니다.
- **기록장**: 구글 시트(성적) + 구글 드라이브(숙제 사진). 화면은 GitHub Pages.
- **수업계획서**: `tools/class-plan` — 지난달 워드 계획서 + 연간 계획표로 다음 달 계획서를 만듭니다.

## 지금 바로 보기 (서버 없이)

`docs/index.html`(학생)과 `docs/admin.html`(강사)을 브라우저로 열면 **미리보기 모드**로 열립니다.
예시 학생 번호 `KM482919`, 강사 비밀번호 `demo`. 예시 데이터라 새로고침하면 처음 상태로 돌아갑니다.
`docs/dev/` 아래 같은 이름의 파일은 **개발판**(빨간 띠)입니다.

## 본판과 개발판

| | 본판 (prod) | 개발판 (dev) |
|---|---|---|
| 주소 | `…/seiseki/` · `…/seiseki/admin.html` | `…/seiseki/dev/` · `…/seiseki/dev/admin.html` |
| 화면 파일 | `docs/` | `docs/dev/` |
| 기록장 | 「성적노트 기록장」 | 「성적노트 기록장(개발)」 — 연습용 가짜 학생만 |
| 원생명단 | 퇴실퀴즈와 같이 쓰는 「帰宅クイズ 원생명단」에 연결 | 연결하지 않음 (개발 기록장 안의 「원생」 탭) |
| 웹앱 주소 | `config.js` 의 `API_URL.prod` | `config.js` 의 `API_URL.dev` |
| 폰 저장(번호 기억 등) | `seiseki.*` | `seiseki-dev.*` (본판과 안 섞임) |

**고치는 순서**: `docs/dev/` 를 고침 → 테스트 → 푸시 → 폰으로 개발판 확인 → `sh tools/promote.sh` 로 본판에 옮김 → 푸시.
Apps Script 를 고쳤다면 개발 기록장의 Apps Script 에 먼저 붙여넣어 확인하고, 그다음 본판 기록장의 Apps Script 에 붙여넣습니다. 둘 다 **배포 관리 → 새 버전**.

## 학생 번호 = 퇴실퀴즈 번호

- 형식: **영문 2자(I·O 제외) + 숫자 6자리**, 끝자리는 확인숫자 (예: KM482919). 퇴실퀴즈와 같은 번호를 씁니다.
- 학생 이름·번호는 원생명단 시트에 있고, 반 정보는 성적노트 기록장의 「수강」 탭에만 있습니다 (원생명단에는 반을 넣지 않기로 함).
- 월초에 강사 화면 「학생·번호」에 aca2000 명단을 붙여넣으면, 원생명단에서 **이름이 똑같은** 학생을 찾아 그 번호를 쓰고, 없는 이름만 새 번호를 만들어 원생명단에 추가합니다. 이름 표기는 aca2000 출석부 그대로(「김민경(동작)」처럼) 맞춰 주세요.
- 학생을 막을 때는 원생명단 「상태」 칸에 「차단」. 번호는 바꾸지 않습니다(퇴실퀴즈 기록이 번호로 이어져 있어서).

## 설치 순서 (처음 한 번)

> 2026-10-17 현재: 기록장 2개와 각 Apps Script(「성적노트 서버」, 「성적노트 서버(개발)」) 코드 붙여넣기, 개발판 초기 설정·웹앱 배포(`config.js` 의 `dev`)까지 끝남. 관리자 비밀번호는 선생님이 직접 메뉴에서 설정.

기록장을 **두 개** 만듭니다: 본판용 「성적노트 기록장」, 개발판용 「성적노트 기록장(개발)」. 아래 1~3을 각각 한 번씩 합니다.

### 1. 기록장 구글 시트에 Apps Script 붙이기
1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. `Code.gs` 내용을 지우고 `apps-script/_합본.gs`(Core·Logic·Code 를 합친 한 파일)를 통째로 붙여넣고 저장(⌘S). `sh tools/bundle-gas.sh` 로 다시 만들 수 있습니다.
4. (선택) 톱니바퀴(프로젝트 설정)에서 시간대가 「(GMT+09:00) 서울」인지 확인합니다.

### 2. 초기 설정
1. 시트로 돌아가 새로고침하면 메뉴에 **성적노트** 가 생깁니다.
2. **성적노트 → 1. 초기 설정** → 권한 요청: 계정 선택 → 「고급 → (안전하지 않음)으로 이동」 → 허용. (내가 만든 스크립트라 구글이 확인 안 된 앱으로 표시하는 것)
3. **「반」 탭**의 반 이름·요일시간을 실제에 맞게 고칩니다. 반코드(첫 칸)는 바꾸지 않습니다.
4. **성적노트 → 2. 관리자 비밀번호 설정** (4자 이상).
5. **본판만**: **성적노트 → 3. 원생명단 시트 연결** → 「帰宅クイズ 원생명단」 주소 붙여넣기. 명단이 비어 있으면 첫 줄 머리글(일련번호·이름·상태·발급일·메모)을 써 넣습니다.

### 3. 웹앱으로 배포
1. Apps Script 편집기 **배포 → 새 배포** → 유형 **웹 앱** → 실행 사용자: **나**, 액세스: **모든 사용자** → 배포.
2. **웹 앱 URL**(…/exec)을 복사해 `docs/assets/config.js` 의 `prod`(본판) 또는 `dev`(개발판) 따옴표 안에 붙여넣습니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 그래야 주소가 그대로입니다.

### 4. GitHub Pages
1. GitHub 에서 새 저장소 `seiseki` 를 만들고(Public) 이 폴더를 push 합니다.
2. 저장소 **Settings → Pages → Branch: main, 폴더: /docs → Save**. 1~2분 뒤 열립니다.
   - 학생: `https://<계정>.github.io/seiseki/` (이 주소를 QR로)
   - 강사: `https://<계정>.github.io/seiseki/admin.html`
   - 개발판: 주소 중간에 `/dev/` (`…/seiseki/dev/`, `…/seiseki/dev/admin.html`)

> 저장소는 공개입니다. 학생 이름·성적·사진은 구글 시트·드라이브에만 있고 GitHub 에는 올라가지 않습니다. `config.js` 의 웹앱 주소로는 번호나 강사 비밀번호 없이 아무것도 볼 수 없습니다.

## 매달 하는 일

| 언제 | 할 일 | 어디서 |
|---|---|---|
| 월초 | aca2000 명단(이름 + 반)을 붙여넣기 → 원생명단에서 번호를 찾고, 새 원생만 번호 발급 → 새 학생에게만 번호 전달 (번호표 복사) | 강사 화면 「학생·번호」 |
| 월초 | 수업계획서 만들기 (아래) | Claude 에게 요청 |
| 시험 전 | 시험 등록 (반·이름·문항 수·정답) | 「시험」 |
| 시험 후 | 학생 이름 → 답안 숫자 입력 → Enter. 틀린 번호를 보고 시험지에 체크 | 「답안 입력」 |
| 숙제 낼 때 | 숙제 등록 (반·교재·쪽 범위·문항 수) | 「숙제」 |
| 수시로 | 제출 사진 보고 「확인」 체크, 미제출자 확인 | 「숙제」 |
| 월말 | 학생평가 한마디 쓰기 → **엑셀 내려받기** 또는 **표 복사** 로 학원 양식에 붙여넣기 | 「월말 표」 |

시트 메뉴 **성적노트 → 학생 화면에 정답 보이기** 를 켜면 학생 화면의 틀린 문항에 정답과 내 답이 함께 보입니다 (기본은 틀린 번호만).

## 수업계획서 만들기

```bash
pip3 install python-docx openpyxl   # 처음 한 번
cd tools/class-plan
python3 class_plan.py --month 2026-11 \
  --prev "~/Library/Mobile Documents/com~apple~CloudDocs/일공/자료/학원/강의계획서/26/10" \
  --out  "~/Library/Mobile Documents/com~apple~CloudDocs/일공/자료/학원/강의계획서/26/11"
```

- 지난달 폴더의 워드 파일마다 같은 양식으로 다음 달 파일을 만들고, 요약 엑셀(`2611_수업계획서.xlsx`)도 같이 만듭니다.
- 날짜·회차·월말테스트·주간 숙제 칸은 자동이고, **수업 내용·교재 범위는 비워 둡니다**(엑셀에서 노란 칸).
- 새해 계획표가 나오면 `calendar_2026.json` 처럼 그 해 JSON 을 만들어 `--calendar` 로 지정합니다. `--check` 로 계획표 횟수와 계산이 맞는지 먼저 확인하세요.

```bash
node tests/logic.test.js      # 채점·번호·명단·조회·숙제 규칙 (개발판 기준)
python3 tests/smoke.py        # 미리보기 모드로 본판·개발판 화면 클릭 테스트 (playwright 필요)

```
