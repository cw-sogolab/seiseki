# 디자인 시안 공통 규격 (시안 A~J, 2026-11-25)

같은 내용을 서로 다른 디자인 방향 10개로 보여 주고 선생님이 고르게 하는 시안입니다. **내용·화면 구성은 10개가 같아야** 비교가 됩니다. 디자인(색·글꼴·모양·캐릭터·문구의 말투)만 방향에 맞게 다르게.

사이트: 학원(일본 유학 시험 EJU 종합과목) 학생용 학습 허브 — 「성적노트」(성적·숙제), 「퇴근 미션」(수업 끝 퇴실 퀴즈: 전부 맞혀야 집에 감), 수업(커리큘럼), 질문(QnA), 그리고 공부하면 캐릭터를 꾸밀 수 있는 기능. 이름은 반드시 **「성적노트」「퇴근 미션」** 으로 씀.

## 파일
- 시안 하나 = `docs/dev/v2/sian-<글자>.html` 한 파일(HTML+CSS+JS). 다른 파일은 만들거나 고치지 않음.
- 외부 리소스는 Google Fonts 와 Pretendard CDN 만. 이미지 파일 없이 SVG·CSS 로만. `<meta name="robots" content="noindex">`.
- 본보기(구조·꾸미기 동작): `docs/dev/v2/sian-a.html`. 디자인은 따라 하지 말 것.

2. **첫째 줄 「필수 화면」** (소제목 표시) — 가로로 나란히, 가로 스크롤 가능:
   - **① 메인** (휴대폰 틀 340×700 안팎): 내 캐릭터 · 오늘 미션 「퇴근 미션 20문제」 · 다음 아이템까지 진행 막대 · 연속 출석 · ★ 240 · 아래 탭 5개 **홈 / 퇴근 미션 / 성적노트 / 수업 / 질문**.
   - **② 성적노트** (휴대폰 틀): 제목 「성적노트」, 과목 칩(정치·경제·현대사회·지리·역사, 하나 선택됨), 요약 숫자 3개(평균 정답률 78% · 최근 테스트 17/20 · 숙제 5/6), 추이 그래프(SVG, 내 점수와 반 평균 두 선 또는 막대, 4~5개 시점), 테스트 목록 3줄(예: 「정치 3주차 소테스트 · 11/18 · 17/20 · 3등 / 18명」), 숙제 줄 2개(제출 완료 / 미제출 배지).
   - **③ 퇴근 미션** (휴대폰 틀): 문제 풀이 화면 — 진행 표시(「집까지 7문제」, 13/20 막대나 점), 과목 태그 「일본 지리」, 문제 「長崎県 — 어느 지방에 속할까?」, 보기 4개 「中国地方 / 九州地方 / 近畿地方 / 四国地方」(각각 작은 한국어 병기: 주고쿠 지방 / 규슈 지방 / 긴키 지방 / 시코쿠 지방), 정답 九州地方 이 선택되어 「정답!」 피드백이 뜬 상태, 「다음」 버튼.
   - **④ 어드민** (PC 화면 틀 가로 900~960 × 세로 600~640, 브라우저 창 모양): 왼쪽 메뉴(답안 입력 · 문항 분석 · 숙제 · 시험 · 학생 · 퇴근 미션 · QnA, 「퇴근 미션」 선택됨), 위쪽 요약 카드 4개(오늘 통과 14 / 18 · 미제출 숙제 6 · 답 안 한 질문 2 · 이번 주 테스트 1), 가운데 표 「오늘의 퇴근 미션」(열: 이름 · 반 · 첫 시도 정답 · 도전 횟수 · 걸린 시간 · 상태 / 가짜 학생 6명: 김예시 · 이샘플 · 박테스트 · 최더미 · 정연습 · 한견본 / 상태 배지: 통과 · 푸는 중 · 아직), 오른쪽 「오늘 암호」 큰 숫자 4자리(가짜, 예 4827) + QR 자리(격자 무늬 네모). 어드민은 업무 화면이므로 장식은 줄이되 **같은 색·글꼴·모양 체계**가 느껴지게.

## 캐릭터·꾸미기
- 캐릭터는 그 방향에 맞게 **새로 디자인**(다른 시안 캐릭터를 복사하지 않음). 표정 2종(기본·기쁨).
- 「몸(색 5종) + 모자(없음/캡/비니/왕관) + 안경(없음/동글/선글라스) + 키링(없음/별/번개/하트)」을 겹쳐 그리는 JS 함수 하나로. 
- **꾸미기는 실제로 동작**: 탭을 바꾸고 아이템을 누르면 캐릭터가 바로 바뀌고 메인·클리어 화면의 캐릭터에도 반영. 시안이므로 잠긴 것도 눌러 입혀 볼 수 있게.
- 잠긴 아이템 조건 문구(예시, 그대로 사용): 「퀴즈 10회 참가」「한 과목 완강」「월말 80% 이상」「7일 연속 출석」「첫 도전 통과 3번」「QnA 첫 질문」「★ 100」.

## 금지·주의
- 실제 학생 이름·숫자 금지(위 가짜 예시만). 실제 브랜드 이름·로고 금지.
- 「자주 나옴」·중요 ★ 같은 출제 빈도 문구 금지(★는 재화 표시로만).
