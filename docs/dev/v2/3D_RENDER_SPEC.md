# 몽글이 3D 렌더 규격서 (2026-11-25)

> 선생님이 3D 프로그램(Blender·Spline·Womp 등)으로 캐릭터와 아이템을 렌더해 주시면, 사이트가 **층을 겹쳐서** 꾸미기를 보여 줍니다.
> 이 규격대로 뽑으면 그림만 바꿔 끼우면 됩니다. 처음에는 **「시작 세트」만** 만들어도 충분합니다.

## 1. 공통 규칙 (모든 이미지가 같아야 겹쳤을 때 딱 맞음)

| 항목 | 값 |
|---|---|
| 캔버스 | **1024 × 1024 px**, 정사각형, **투명 배경 PNG** |
| 카메라 | 모든 파일 **같은 카메라·같은 위치·같은 화각**(정면에서 아주 살짝 위, 약 10°). 렌더할 때 카메라를 절대 움직이지 않기 |
| 캐릭터 위치 | 발바닥이 아래에서 **80px** 위, 몸 가운데가 가로 **512px** — 기본 몸 파일에서 정해지면 나머지는 같은 장면에서 렌더하니 자동으로 맞음 |
| 조명 | 모든 파일 같은 조명. 주광은 **왼쪽 위**(사이트의 다른 아이콘도 왼쪽 위 빛) |
| 바닥 그림자 | **몸 파일에만** 넣기(아이템 파일에는 넣지 않음 — 겹치면 그림자가 진해짐) |
| 재질 | 무광~반광 점토(SSS 약하게 + 아주 약한 노이즈 범프). 지금 시안 B 몽글이 느낌 |
| 파일 이름 | 영문 소문자·숫자·하이픈만. 예: `hat-cap-blue.png` |

### 층(레이어) 순서 — 아래에서 위로
1. `body-<색>.png` — 몸(팔·발 포함) + 바닥 그림자
2. `face-<표정>.png` — 눈·입·볼(몸 색과 상관없이 하나로 씀)
3. `glasses-<이름>.png` — 안경
4. `hat-<이름>.png` — 모자
5. `charm-<이름>.png` — 키링(몸 옆구리에 걸린 상태)

> 모자가 머리를 감싸 가리는 부분은 **모자를 씌운 상태에서 모자만** 렌더하면 자연스럽습니다(Blender: 몸을 「Holdout」 으로 두고 모자 렌더). 어려우면 그냥 모자만 렌더해도 됩니다 — 약간 떠 보이는 정도.

### 표정 (얼굴 층)
| 파일 | 표정 | 쓰는 곳 |
|---|---|---|
| `face-base.png` | 기본 | 평소 |
| `face-happy.png` | 기쁨(눈 ＾＾, 입 벌림) | 정답·클리어·아이템 획득 |
| `face-wow.png` | 놀람(동그란 눈, o 입) | 잠긴 아이템·새 기록 |
| `face-blink.png` | 눈 감음 | 깜빡임 애니메이션 (선택) |

## 2. 시작 세트 (먼저 이것만 — 약 25장)

| 종류 | 개수 | 파일 |
|---|---|---|
| 몸 색 | 5 | `body-lavender` · `body-peach` · `body-mint` · `body-sky` · `body-butter` |
| 표정 | 3(+1) | `face-base` · `face-happy` · `face-wow` (+ `face-blink`) |
| 모자 | 6 | `hat-cap` · `hat-beanie` · `hat-crown` · `hat-headphone` · `hat-hood` · `hat-bucket` |
| 안경 | 4 | `glasses-round` · `glasses-sun` · `glasses-square` · `glasses-star` |
| 키링 | 6 | `charm-star` · `charm-heart` · `charm-bolt` · `charm-chain` · `charm-fuji`(후지산) · `charm-sakura`(벚꽃) |

> 고등학생·재수생용이라 **귀여운 것 + 멋있는 것**(선글라스·비니·헤드폰·후드·체인)을 반반 섞었습니다. 후지산·벚꽃은 「일본 유학」 학원다운 아이템.

### 등급 (2026-11-25 선생님 결정: 성적 = 희귀, 성실 = 힙)
| 등급 | 얻는 방법 | 느낌 | 시작 세트 예시 |
|---|---|---|---|
| 기본 | 처음부터 가짐 | 단순한 것 | 캡 · 동글 안경 · 별 키링 · 몸 색 2종 |
| **힙** | **성실** — 연속 출석 · 숙제 기한 내 제출 · 퇴근 미션 참가·첫 도전 통과 | 멋있고 트렌디(스트리트) | 비니 · 헤드폰 · 후드 · 선글라스 · 체인 키링 · 번개 키링 |
| **희귀** | **성적** — 기준 점수 달성 · 지난달보다 오름 · 만점 | 반짝이는 금·보라, 수가 적음 | 왕관 · 별 안경 · 후지산 키링 · 벚꽃 키링 |
- 희귀 아이템은 렌더할 때 **금속광·반짝임**을 더해 한눈에 귀해 보이게.
- 힙 아이템은 **수가 가장 많게** — 성실하면 누구나 계속 얻을 수 있어야 함.

## 4. 보내 주실 때
- 한 폴더에 모아 `일공/` 아래 아무 곳(예: `일공/_작업/몽글이_렌더/`)에 넣고 위치만 알려 주세요.
- 첫 몇 장(몸 1 + 표정 1 + 모자 1)만 먼저 보내 주시면, 사이트에 끼워서 위치가 맞는지 확인한 뒤 나머지를 뽑으시는 게 안전합니다.
- 사이트에서는 1024px 원본을 그대로 쓰지 않고 크기별(256·128·64px)로 줄여 씁니다(줄이는 작업은 제가 함).
